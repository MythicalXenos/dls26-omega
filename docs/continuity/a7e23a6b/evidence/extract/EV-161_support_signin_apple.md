# EV-161 (full-page) — How do I setup a "Sign in with Apple" account?
source: https://support.ftgames.com/hc/en-us/articles/360009450097 | official-stated | fetched 2026-10-11T00:16Z | closed for comments
OPERATIVE CONTENT:
- "Sign in with Apple" = cloud saving using Apple ID (NOT iCloud itself; iCloud account required). Requires Apple ID with two-factor auth + signed into iCloud with same ID.
- DLS steps: Settings (cog, top-left) > Advanced > toggle "Sign in with Apple" to "Connected". Then PLAY A FEW MATCHES so save uploads (stable Wi-Fi recommended).
- Score! Match variant steps included (sibling game).
SECURITY/PROFILE (OMEGA-PROFILE-001): save upload is NOT instant — matches played before sync completes are at-risk on device loss; back up BEFORE risky ops.
