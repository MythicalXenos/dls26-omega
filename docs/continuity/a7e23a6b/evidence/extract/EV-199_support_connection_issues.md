# EV-199 (full 1/1) — OFFICIAL support: connection issues during a match (ref-support-connection-issues)
source: https://support.ftgames.com/hc/en-us/articles/7917279109777-I-keep-having-connection-issues-during-a-match-what-can-I-do | official-support | fetched 2026-10-11T12:33Z
OPERATIVE CONTENT (official troubleshooting playbook): disable VPN; on mobile data move to better signal + ensure 4G/5G; on Wi-Fi sit close to router; reset router; try a different Wi-Fi. KNOWN FIX: set DNS to **8.8.8.8** — iOS: Settings > Wi-Fi > Configure DNS > Manual > delete servers > add 8.8.8.8; Android: long-press Wi-Fi > Modify Network > Advanced > DHCP > Static > DNS 8.8.8.8; then Airplane-mode toggle 5s, relaunch game.
