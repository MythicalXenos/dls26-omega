OPERATIVE CONTENT:
- WARNING: users must not loan, exchange, share, sell and/or buy game profiles (Terms of Use).
- Never share personal details (loss unrecoverable).
- User ID path: DLS -> Options (gear, top-left) -> Advanced -> System Info ("i") -> Copy Info. Submit only to FTG staff when asked.
SECURITY NOTE: User ID / system info are identity-adjacent; treat as sensitive — never commit real values to evidence.
