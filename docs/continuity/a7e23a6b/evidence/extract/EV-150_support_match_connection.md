# EV-150 (full-page) — I keep having connection issues during a match, what can I do?
source: https://support.ftgames.com/hc/en-us/articles/7917279109777 | official-stated | fetched 2026-10-10T23:28Z | closed for comments
OPERATIVE CONTENT (troubleshooting ladder): disable VPN; on mobile data move to better signal + use 4G/5G; play near Wi-Fi router; reset router; try different Wi-Fi. Known fix: set DNS to 8.8.8.8 manually (iOS: Wi-Fi > Configure DNS > Manual; Android: Wi-Fi > Modify Network > Advanced > DHCP > Static) then airplane-mode toggle; restart game.
