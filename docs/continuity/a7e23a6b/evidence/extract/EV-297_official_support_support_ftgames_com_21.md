## Summary

OFFICIAL FTG SUPPORT (articles 214387685, 4413273241873): For DLS/UCS/Score!Hero/Score!Match, link game profile via 'Sign in with Google' (Android) or 'Sign in with Apple' (iOS 13+) via in-game Settings. Save data NOT secured via Google Play Games, iCloud, Facebook, or Game Center (those are separate/not used). Same-OS additional devices: sign in with same Google/Apple account. NOTE: IAPs and save data CANNOT be transferred across platforms (Android↔iOS) officially; no Facebook/Game Center cloud save supported. Signing out unlinks profile and risks data loss on uninstall/device change. Older DLS (pre-DLS19, now unavailable): iCloud/Google Play Saved Games only. COMMUNITY (SakibPro) CLAIMS DLS26 added cross-platform transfer via Settings→Advanced→Manage Device→Generate Code (5-minute one-time code) then Settings→Advanced→Link Profile on new device; max 3 devices per profile sharing career progress. This contradicts official support; may reflect a DLS26 feature added after the support article's last update (May/Dec 2024) OR may be inaccurate.
