## Summary

DLS player attributes (NOT FIFA PAC/SHO/PAS/DRI/DEF/PHY; DLS uses 8 OUTFIELD stats + 2 GK stats): SPE (Speed = max sprint speed), ACC (Acceleration = time to reach top speed; shorter players accelerate faster per DLS height mechanic), STA (Stamina = endurance over 90min; drains with sprinting/pressing/running), STR (Strength = physical duels, hold-off play), TAC (Tackling = defensive tackle success, outfield only), CON (Control = ball control/dribbling/1st-touch — used as weighted premium attribute in coach upgrades), PAS (Passing = pass accuracy/speed), SHO (Shooting = finishing/shot power/accuracy). GKs have GKH (Handling) + GKR (Reflexes) only (no Positioning stat separate; GK position selection is tied to GKR in community sim). Attributes display on player cards as 0-100 scale in-game but database values (dlsinside.com scraper) appear 3-digit scaled (0-999 or 0-1000, e.g. Anthony Gordon SPE 909/ACC 899/STA 839/STR 569/TAC 409/CON 809/SHO 789/PAS 748/GKR 142/GKH 174 corresponding to in-game ~91/90/84/57/41/81/79/75; Desailly Classic CB ACC 750/SPE 800/STA 890/STR 920/TAC 900/SHO 520/GKR 270). Coach categories align exactly to attribute groups: Fitness = SPE+ACC+STA+STR; Technical = CON+TAC+PAS+SHO (note: earlier sources listed TAC under Fitness; gamedls.net places TAC under Technical — to be verified); Goalkeeping = GKH+GKR. Position-relevant attribute targets widely circulated (ST prioritize SPE/ACC/SHO/STR; mid prioritize STA/CON/PAS; defend prioritize STR/TAC/STA/CON; wingers SPE/ACC/STA/CON). Height impacts acceleration (shorter = faster acceleration at same ACC stat) per r/DLS mechanic deep-dive. CON (Control) and SPE are the highest-weight/cost attributes in coach upgrade progression; STA lowest cost.
