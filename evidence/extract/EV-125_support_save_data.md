# EV-125 (full-page) — How is save data stored and transferred in DLS?
source: https://support.ftgames.com/hc/en-us/articles/4413273241873 | official-stated | fetched 2026-10-10T21:08Z | closed for comments
OPERATIVE CONTENT:
- "we have limited each player to one DLS account" (fair/secure/robust environment).
- Manage Devices + Link Profile live in Options (gear) -> Advanced tab.
- Transfer via Sign in with Google (Android only) / Sign in with Apple (iOS only); never share personal details (loss unrecoverable).
- Transfer via one-time CODE: Manage Devices on old device -> Generate Code (subject to device limit) -> Link Profile on new device; recommended for cross-platform (Android<->iOS); code unusable on the generating device; never share codes (loss unrecoverable).
- Linked-device list manageable (X removes devices).
- Signing OUT of Google/Apple at any point unlinks the account from the profile; profile becomes susceptible to loss on uninstall/device change.
DEVICE-PIPELINE RELEVANCE: sanctioned state routes are Google/Apple sign-in or one-time codes. Account-link codes are SECRETS (OMEGA-DEVICE-001): never committed to evidence, never requested for our files.
