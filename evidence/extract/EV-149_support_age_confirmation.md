# EV-149 (full-page) — Age Confirmation & Personal Ads and Notifications
source: https://support.ftgames.com/hc/en-us/articles/4408249822609 | official-stated | fetched 2026-10-10T23:20Z | closed for comments
OPERATIVE CONTENT:
- Age confirmation at first download (age bandings); set once (change only via support + User ID).
- Younger bandings: same ad VOLUME but less personalised; no personalised alerts/promotions; some features/gameplay elements withheld "that we feel are not appropriate to minors... including social media integrations".
- Personalised Ads / Personalised Notifications toggles; youngest band = personalisation permanently OFF.
ELIGIBILITY FLAG (CLAIM-003): age banding CAN gate features; if leaderboards/social features are age-gated in DLS26, ranking eligibility must account for it. Unverified whether leaderboards specifically are gated.
