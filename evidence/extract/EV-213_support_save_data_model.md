# EV-213 (full 1/1) — OFFICIAL support: How is save data stored and transferred in DLS? 4413273241873 — ACCOUNT MODEL
source: https://support.ftgames.com/hc/en-us/articles/4413273241873-How-is-save-data-stored-and-transferred-in-DLS | official-support | fetched 2026-10-11T17:42Z
OPERATIVE CONTENT (verbatim core): **one DLS account per player** (fair/secure/robust rationale). **"Manage Devices" + "Link Profile" buttons: Main Menu > Options (gear) > Advanced tab.** Transfer via sign-in: same Google (ANDROID ONLY) / Apple (iOS ONLY) account on own additional devices. Transfer via CODE (recommended for CROSS-PLATFORM Android<->iOS): old device Manage Devices > "Generate Code" (only under device limit) > enter in "Link Profile" on new device; code cannot be used on the generating device. Manage Devices lists linked devices (X to remove) — DEVICE LIMIT exists. **SIGN-OUT HAZARD: signing out of Google/Apple at ANY point unlinks the provider from the game profile — susceptible to LOSS on uninstall/device change.** Codes/credentials must never be shared — lost = unrecoverable.
