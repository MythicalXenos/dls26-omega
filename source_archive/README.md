# SOURCE ARCHIVE

Complete raw content from large sources, for internal verification only. `logs/main_operational_log.md` and `logs/sources_visited.json` reference the location.

- Filename: `{domain}__{slug}__{YYYY-MM-DD}.{ext}`
- Anything shared externally in an Audit Package reproduces only what is needed to support the specific claim being checked — never a whole scraped page.
- Never pruned. Rotate by adding files, not by overwriting.
- Exempt from the KB rotation thresholds (SCHEMA.md §3) but counted against total repo size.
