## Mod-APK landscape + RISK ASSESSMENT (turn 11, S-0056; G-0043 documented — All-Methods disclosure with explicit risk)
**What it is (dlskiturl.com/dls-26-mod-apk/, read-only survey):** a third-party "DLS 26 Mod" APK with unlimited coins/gems, custom faces, and **40+ modder-added legends (Drogba, Di Stéfano, Garrincha, Müller, Ronaldinho, Platini, Cantona…)** beyond the official 21-player classic pool. **It is NOT the real DLS26 client: the base is a DLS19-era build** ("the base transfer window used is of DLS 19", 32-player accommodation limit; Clans missing — "still trying to add this feature to this older version"). Cover branding "Salah and Raphinha" (official store: Raphinha & Alvarez). Install requires Unknown Sources. Comments report broken installs, a money glitch (must buy a <1,200-coin player first), and requests for a "Speed mod".
**Risk assessment (for the record; NOT an endorsement):** (1) **BAN/ACCOUNT RISK — extreme:** a modified client + impossible economy in DLS Live is the most detectable violation class; FTG can ban account+device. (2) **SECURITY RISK — high:** unsigned third-party APK = malware/credential theft vector; no provenance. (3) **STATE RISK:** the mod is a different game base — it cannot hold real DLS26 progress; mixing corrupts state. **Never install on the user's Samsung or the test device without explicit informed user consent at advisory time; the legitimate research value is defensive** (recognize modded opponents in DLL; wishlist signals for future classic rounds; engine/squad-cap contrasts).
**Sibling mechanics pages discovered on dlsmod.com (sister site):** dlsmod.com/dls-clans/ (Clans: create/join groups, customize, rank via Clan Points from matches+events — a second source for the Clan system, G-0059) and **dlsmod.com/c-spamming-in-dls/ — a named gameplay exploit ("C-spamming") tied to DLS Live Tier 1 play** => G-0069 (study + countermeasures; do not execute).
