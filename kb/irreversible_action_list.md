# IRREVERSIBLE ACTION LIST

Per PROMPT.md §8: a standing record of **game knowledge**, not of the user. Read at session start; it is what the proactive warning in PROMPT.md §1 checks the user's stated intent against. Built during the Step 1 sweep, presented at first contact, updated as new action types are discovered. Which actions qualify is determined by exhaustive knowledge of the game, never by a fixed list frozen when the prompt was written.

**Definitions.** IRREVERSIBLE = cannot be undone at all. CONSEQUENTIAL = can be undone, but only at a cost worth avoiding (resources spent, progress reset, sequencing broken, an opportunity that does not return). Both get the warning.

No entry is written from recall (zero ungrounded claims invariant); each carries an `S-NNNN` source reference.
